# Демонстрационные данные

После применения миграций из корня проекта:

```sh
docker compose exec backend python -m app.seed
```

При локальном запуске без Docker из папки backend:

```sh
python -m app.seed
```

Скрипт использует DATABASE_URL из окружения. Для наполнения production-базы
команду запускает ответственный за сервер, используя docker-compose.prod.yml.

Добавляются 41 демонстрационный игрок, 8 команд по 5 игроков, 6 турниров
(2 идут, 3 открыты для регистрации, 1 завершён) и 42 одобренные заявки.
Турниры помечены префиксом [DEMO]. Демопользователи не имеют настоящих Discord ID.
Даты новых турниров рассчитываются относительно первого запуска в UTC.

Повторный запуск пропускает существующие записи, сохраняет их даты и результаты.
Все добавления выполняются в одной транзакции. В PostgreSQL параллельные запуски
сериализуются блокировкой. Скрипт не создаёт матчи и не генерирует сетку.

На главной данные из базы видны при NEXT_PUBLIC_API_MOCKS=false после пересборки фронтенда.
