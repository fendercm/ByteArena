# Как мы работаем

## Золотые правила

**Архитектура**
1. **Логика живёт только в бэкенде.** База, проверки и правила турнира — только в FastAPI. Next.js показывает и отправляет.
2. **Контракт API — закон.** `openapi.json` описывает, как общаются фронт и бэк. Менять API: сначала контракт и сообщение в чат, потом код.
3. **Базу руками не трогаем.** Любые изменения структуры — только через миграции Alembic.

**Git и код**
4. **main всегда рабочий.** Прямые пуши запрещены, всё через pull request.
5. **Одна задача — одна ветка — один PR.** Маленькие PR проверяются за минуты.
6. **Ревью в течение суток.** PR в бэкенд одобряет A или B, во фронтенд — C или E.
7. **Перед PR проверь у себя.** Линтер проходит, тесты зелёные, проект запускается. Код сетки без тестов не вливается.
8. **Секреты не коммитим.** Ключи только в `.env`, в репозитории — `.env.example`.

**Команда**
9. **Не успеваешь — скажи сразу**, а не в день дедлайна.
10. **Застрял больше чем на 2 часа — спрашивай.**
11. **Договорились — записали** в чат или README.
12. **Знай модуль напарника.** У каждого модуля есть дублёр.

**Нулевая версия**
13. **До 10 декабря ничего сверх плана.** Новые идеи — в список «после MVP».
14. **Работает важнее, чем красиво.**

## Ветки и коммиты

- Ветки: `feature/<что-делаю>`, `fix/<что-чиню>`, например `feature/db-schema`, `fix/bracket-odd-teams`.
- Коммит описывает, что изменилось: «Схема БД: таблицы турниров и команд», а не «правки».

```bash
git checkout main && git pull
git checkout -b feature/db-schema
# ...работа...
git add . && git commit -m "Схема БД: таблицы турниров и команд"
git push -u origin feature/db-schema
# на GitHub: Compare & pull request → ревьюер
```

## Проверки перед PR

```bash
# бэкенд
cd backend
ruff check . && ruff format --check .
pytest

# фронтенд
cd frontend
npm run lint
```

## Договорённости по API

- Списки: `{"items": [...], "total": 42}`
- Ошибки: `{"detail": "текст ошибки"}`
- Даты: ISO 8601 с часовым поясом, `2026-11-05T18:00:00+03:00`
- Поля: `snake_case`
- В коде бэкенда роуты пишутся без `/api` (`/tournaments`), в браузере они доступны как `/api/tournaments`.
