# Форма создания турнира

`/tournaments/new` использует общий UI из `main`: Manrope, цветовые переменные,
кнопки, шапку и подвал. Дополнительные стили ограничены `.tournament-page`.

Форма работает с текущим контрактом бэкенда:

- `GET /api/me` — пользователь из HttpOnly cookie; 401 означает гостя.
- `GET /api/auth/discord/login` — начало входа. Callback бэкенда возвращает на `/`;
  фронтенд запоминает возврат к форме на 10 минут только в текущей вкладке.
- `POST /api/auth/logout` — выход, ответ без тела (204).
- `POST /api/tournaments` — `title`, `starts_at`, `max_teams`, `rules`; организатора
  и статус задаёт бэкенд. В форме время вводится в МСК и передаётся в UTC.
- `GET /api/tournaments/{id}` — публичная страница созданного турнира.

Ошибки FastAPI 422 показываются у полей; 401 при отправке просит повторный вход.
Черновик сохраняется в `sessionStorage`. При запрете хранения форма продолжает
работать, но нужно вернуться через пункт «Организатор». Секреты и токены входа
фронтенд не читает и не хранит.

После успешного создания открывается страница нового турнира со ссылкой и
кнопкой копирования. Если Clipboard API недоступен, ссылка выделяется вручную.

Проверки: `npm test` (8 тестов контракта API), `npm run lint`, `npm run build`.
Для полного локального запуска используйте Docker Compose из корня. Для запуска
фронтенда отдельно можно задать `API_PROXY_TARGET=http://127.0.0.1:8000` перед
`npm run dev`. Production `output: standalone` сохранён для Dockerfile.prod.
